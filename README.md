# TaskFlow

TaskFlow is a lightweight project and task management API. It helps individuals and small teams organise projects, assign tasks and track their progress.

## Objectives

- Build and test a REST API with Node.js, Express.js and PostgreSQL
- Collaborate on a shared codebase using Git branches and pull requests
- Review each other's work before it is merged
- Keep code consistent with linting and automated checks (CI/CD)
- Document the application as we build it

## Tech stack

| Area | Tool |
|---|---|
| Runtime | Node.js |
| Web framework | Express.js |
| Database | PostgreSQL |
| Version control | Git and GitHub |

## Getting started

The application is in its initial setup stage. Installation steps will be added once the first features are built.

## Contributing

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before making changes. In short:

1. Create a new branch for each task.
2. Commit your changes with a clear message.
3. Open a pull request.
4. Wait for a review before merging into `main`.
